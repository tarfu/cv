= CV System - Übersicht & Schnellstart

== 🎯 Was ist das?

Ein professionelles CV-Management-System basierend auf AsciiDoc, das Ihnen erlaubt:

* ✅ **Inhalte zentral pflegen** - Eine Quelle, viele Formate
* ✅ **Verschiedene Designs** - jernoxIT, Minimal, oder eigene Themes
* ✅ **Einfache Updates** - Assistenz kann alles in einfachen Textdateien pflegen
* ✅ **Versionierung** - Git-freundlich, nachvollziehbare Änderungen
* ✅ **Automatische Builds** - Ein Befehl, mehrere PDF-Varianten

== 📁 Struktur

----
cv-system/
├── cv-main.adoc              # Hauptdatei (Master)
├── photo.jpg                 # ⭐ IHR FOTO (ersetzen!)
├── attributes.adoc           # ⭐ Variablen (Rate, Datum, etc.)
├── sections/                 # ⭐ Inhalt (hier wird gearbeitet)
│   ├── contact.adoc
│   ├── skills.adoc
│   ├── profile.adoc
│   ├── projects-current.adoc # ⭐ Aktuelle Projekte hinzufügen
│   ├── projects-archive.adoc
│   ├── competencies.adoc
│   ├── education.adoc
│   └── locations.adoc
├── themes/                   # Design-Themes
│   ├── jernoxit-theme.yml
│   └── minimal-theme.yml
├── output/                   # Generierte PDFs
├── build.sh                  # ⭐ Ausführen für PDF-Erstellung
├── install.sh                # Einmalige Installation
├── README.adoc              # Ausführliche Dokumentation
├── QUICK-REFERENCE.adoc     # Cheatsheet
└── CHANGELOG.adoc           # Änderungshistorie
----

⭐ = Diese Dateien werden am häufigsten bearbeitet

== 🚀 Schnellstart (3 Schritte)

=== 1. Installation (einmalig)

[source,bash]
----
cd cv-system
./install.sh
----

Installiert Ruby, AsciiDoctor und AsciiDoctor-PDF.

=== 2. Inhalt pflegen

Öffnen Sie die Dateien in `sections/` mit einem beliebigen Texteditor:

* **Neues Projekt hinzufügen**: `sections/projects-current.adoc`
* **Rate ändern**: `attributes.adoc` → `:hourly-rate:`
* **Verfügbarkeit ändern**: `attributes.adoc` → `:availability-date:`

=== 3. PDFs generieren

[source,bash]
----
./build.sh
----

Fertig! PDFs sind in `output/`:

* `CV_Tobias_Breitwieser_Vollversion.pdf` - Alle Projekte, jernoxIT Design
* `CV_Tobias_Breitwieser_Kurzversion.pdf` - Ohne alte Projekte
* `CV_Tobias_Breitwieser_Minimal.pdf` - Minimalistisches Design

== 📚 Dokumentation

[cols="2,3"]
|===
|Datei |Zweck

|`README.adoc`

|`FOTO-ANLEITUNG.adoc`

|`attributes-en.template`

== 💡 Häufigste Aufgaben

=== Neues Projekt hinzufügen

1. Öffne: `sections/projects-current.adoc`
2. Füge am Anfang ein:

[source,asciidoc]
----
=== MM/YYYY - MM/YYYY | Projekttitel

*Rolle:* Ihre Rolle +
*Kunde:* Kundenname

Projektbeschreibung...

*Technologien:* Tech1, Tech2, Tech3

'''
----

3. Ausführen: `./build.sh`

=== Stundensatz ändern

1. Öffne: `attributes.adoc`
2. Ändere: `:hourly-rate: 130,0 EUR`
3. Ausführen: `./build.sh`

=== Altes Projekt archivieren

1. Projekt aus `sections/projects-current.adoc` ausschneiden
2. In `sections/projects-archive.adoc` als Tabellenzeile einfügen
3. Ausführen: `./build.sh`

== 🎨 Design anpassen

Die Designs sind in `themes/*.yml` definiert. Das jernoxIT-Theme verwendet:

* **Teal**: #1b7b8a (Hauptfarbe)
* **Light Green**: #7ec9a4 (Akzentfarbe)
* **Gray**: #4a4a4a (Textfarbe)

Änderungen am Theme erfordern Kenntnisse in YAML und dem Asciidoctor-PDF Theming System.

== 🔄 Workflow-Empfehlung

1. **Git initialisieren**: `git init` im cv-system Verzeichnis
2. **Änderungen committen**: Nach jedem Update
3. **Build ausführen**: Vor dem Versenden an Kunden
4. **Changelog pflegen**: Änderungen dokumentieren

== ❓ Hilfe & Support

[cols="2,3"]
|===
|Problem |Lösung

|PDF wird nicht generiert
|Prüfen Sie `./install.sh` und Syntax-Fehler

|Formatierung falsch
|Siehe `QUICK-REFERENCE.adoc` für Syntax

|Theme wird nicht angewendet
|Prüfen Sie Theme-Pfad in build.sh

|Weitere Fragen
|Siehe `README.adoc` Troubleshooting-Sektion
|===

== 📦 System-Anforderungen

* **Betriebssystem**: Linux (Ubuntu/Debian empfohlen) oder macOS
* **Ruby**: Version 2.5 oder höher
* **Speicherplatz**: ~50 MB
* **Editor**: Beliebiger Texteditor (VS Code, Sublime, vim, nano, etc.)
