== Änderungen dokumentieren

Wenn Sie Änderungen vornehmen, fügen Sie hier einen Eintrag hinzu:

----
== [X.Y.Z] - YYYY-MM-DD

=== Added (Neu hinzugefügt)
* Neues Feature oder neuer Inhalt

=== Changed (Geändert)
* Änderungen an bestehendem Inhalt

=== Fixed (Behoben)
* Fehlerkorrekturen

=== Removed (Entfernt)
* Entfernte Features oder Inhalte
----

Beispiel:

----
== [1.0.1] - 2025-12-15

=== Added
* Neues Projekt: Cloud Migration für Automobilhersteller

=== Changed
* Stundensatz aktualisiert auf 130 EUR
* Verfügbarkeitsdatum auf 15.02.2026 geändert
----
